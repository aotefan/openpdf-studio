OpenPDF Studio is an independent Apple Silicon PDF editor informed by bounded WPS PDF interaction research. Edit text and images, organize pages, run local OCR and export text-based Word documents.

0.1.14 source preview. No public installer yet. Desktop launch and packaging await a security-patched Electron runtime and regression checks. Current status.

Common PDF tasks, openly implemented.

Text and images

Inline text editing, pointer-positioned text insertion and bounded image transforms. Complex layouts can be rejected.

Pages and exports

Rotate, merge, split, extract and reorder. Export DOCX text, XLSX tables/text, PPTX page images, PNG and TXT.

Local OCR and batches

Apple Vision Chinese/English text recognition and multiple-file conversion. No document upload service.

What does WPS PDF reverse engineering mean?

REA was used to observe normal UI behavior and inspect bounded module evidence in WPS 12.1.28496. Ghidra analysis was limited to configuration initialization. No proprietary code, WPS assets or membership bypass is included. PDF operations are independently built using PyMuPDF.

Is it a complete WPS PDF replacement?

No. It is an early source preview for common workflows. General paragraph reflow, lossless Office conversion, forms and signatures are not complete. It currently targets macOS Apple Silicon with switchable Chinese/English menus, not document translation.

Is it free?

The source and implemented features have no membership fee. AGPL-3.0-or-later obligations apply. The project is unaffiliated with WPS/Kingsoft and similarly named Java OpenPDF libraries.
