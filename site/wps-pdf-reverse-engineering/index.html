WPS PDF / REA / REVERSE ENGINEERING

逆向研究 WPS PDF，
独立实现免费 PDF 编辑器。

研究交互方式，记录已知与未知，再选择成熟开源技术实现。

研究对象与方法

基准：WPS Office 12.1.28496，macOS 中文 PDF 界面。观察日期：2026-10-14 至 2026-10-15。REA 用于原生界面观察与模块分析，系统鼠标/键盘自动化用于实际操作；Ghidra 只用于定向函数研究。

观察等级对产品的意义
点击正文定位，输入触发文字编辑A：本地直接观察页面内输入，减少侧栏与确认步骤
Qt、CoreText、CoreGraphics 模块依赖A：存在性理解模块边界，不推断具体算法
PDFium 相关类名与路径字符串B：推断线索不等于完整引擎验证
键盘编辑配置与静态字符串相关B：推断配置初始化不是输入处理调用链
重排、字体子集、保存事务、OCR 内部算法D：未知独立选择开源方案，不编造内部实现

独立实现，而非专有代码移植

OpenPDF Studio 使用 React / Electron 组织界面，PyMuPDF 负责 PDF 操作，Apple Vision 提供本地 OCR。当前以安全文字片段编辑为主，尚无通用段落重排。

不绕过会员，不调用无权限服务。原始 WPS 二进制、资源索引和反编译输出不进入公开仓库。公开研究摘要来自本地记录，不等于提供了全部独立复现证据。
