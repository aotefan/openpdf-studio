WHAT IT DOES

从一次改字，到一组 PDF 的整理。

01 / EDIT

直接在 PDF 页面上改字

点击正文定位，输入进入编辑；鼠标放置新增文字，点击其他位置应用，可撤销。

02 / ORGANIZE

让页面整理少几步

旋转、增删、前后移动直接执行；支持多选、合并、拆分、提取、页码和水印。

03 / CONVERT

常用转换，集中处理

PDF 转 Word 文字版、Excel 表格或文字行、PPT 页面图片、PNG ZIP 与 TXT。

04 / OCR

中英文 OCR，本机完成

利用 Apple Vision 识别扫描页，添加搜索文字层；不上传文档，不承诺识别零错误。

05 / BATCH

多份 PDF，批量转换

选择多份磁盘文件和目标格式，核对输出清单后执行；取消或失败丢弃临时结果。

06 / OPEN SOURCE

看得见源码，也看得见边界

AGPL 开源。公开实现、测试和限制，不把截图相似当作完整功能复刻。

文字以安全水平片段为主，复杂布局不保证保真。单份输入上限 60 MB / 500 页。查看完整功能边界 →

RESEARCH → INDEPENDENT IMPLEMENTATION

“逆向 WPS PDF”，我们做到了哪一步？

使用 REA 观察 WPS 12.1.28496 中文界面，对模块依赖、字符串和少量交叉引用做只读研究；用 Ghidra 定向查看配置初始化函数。研究帮助确定交互方式，独立编辑器使用 PyMuPDF 等开源组件处理 PDF。

WPS 的段落编辑、字体重建和保存内部算法没有被完整验证。项目不发布 WPS 程序、专有图标或反编译输出，不破解会员。

CLEAR ANSWERS

关于免费 PDF、OCR 和 WPS 平替

OpenPDF Studio 是免费 PDF 编辑器吗？

是。源码和已实现功能不设会员收费，采用 AGPL-3.0-or-later；当前发布源码预览，暂不提供安装包。

可以免费修改 PDF 原有文字吗？

支持安全的水平文字片段编辑、替换和删除，也可用鼠标放置新文字。复杂字体或段落可能无法直接修改，不承诺任意 PDF 无损编辑。

PDF 转 Word 能保留原排版吗？

当前导出 DOCX 文字段落，不能保证多栏、表格、文本框和分页完整保留；扫描件需要先 OCR。

逆向 WPS PDF 是破解会员吗？

不是。项目使用 REA 观察正常界面并做有边界的只读模块研究；应用独立实现，不绕过会员校验、不复制专有代码、不依赖 WPS 服务。

PDF 会上传到服务器吗？

应用的编辑、渲染、OCR 和转换在本机完成。安装依赖和查询版本需要网络，但不发送 PDF。项目网站没有文件上传功能。

支持哪些系统？双语指什么？

当前验证 macOS Apple Silicon；中文和英文指菜单等界面语言，不是翻译 PDF 内容。Windows、Linux、Intel Mac 尚未完成支持验证。

为什么现在没有安装包？

2026-10-22 核验的 Electron 稳定版本仍内置低于最新安全补丁要求的 Node。源码和测试已公开，桌面发行等待上游安全升级及回归。

和 WPS 或 Java OpenPDF 有关系吗？

没有隶属关系。OpenPDF Studio 是独立桌面项目，不是 WPS 官方产品，也不是 Java OpenPDF 库。
