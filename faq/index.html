FAQ / PROJECT FACTS

免费 PDF 编辑器，
先把问题说清楚。

OpenPDF Studio 是免费 PDF 编辑器吗？

是。源码和已实现功能不设会员收费，采用 AGPL-3.0-or-later；当前发布源码预览，暂不提供安装包。

可以免费修改 PDF 原有文字吗？

支持安全的水平文字片段编辑、替换和删除，也可用鼠标放置新文字。复杂字体或段落可能无法直接修改，不承诺任意 PDF 无损编辑。

PDF 转 Word 能保留原排版吗？

当前导出 DOCX 文字段落，不能保证多栏、表格、文本框和分页完整保留；扫描件需要先 OCR。

逆向 WPS PDF 是破解会员吗？

不是。项目使用 REA 观察正常界面并做有边界的只读模块研究；应用独立实现，不绕过会员校验、不复制专有代码、不依赖 WPS 服务。

PDF 会上传到服务器吗？

应用的编辑、渲染、OCR 和转换在本机完成。安装依赖和查询版本需要网络，但不发送 PDF。项目网站没有文件上传功能。

支持哪些系统？双语指什么？

当前验证 macOS Apple Silicon；中文和英文指菜单等界面语言，不是翻译 PDF 内容。Windows、Linux、Intel Mac 尚未完成支持验证。

为什么现在没有安装包？

2026-10-22 核验的 Electron 稳定版本仍内置低于最新安全补丁要求的 Node。源码和测试已公开，桌面发行等待上游安全升级及回归。

和 WPS 或 Java OpenPDF 有关系吗？

没有隶属关系。OpenPDF Studio 是独立桌面项目，不是 WPS 官方产品，也不是 Java OpenPDF 库。
