# OpenPDF Studio 使用说明

打开 PDF 后，通过左侧缩略图或底部页码导航；右下角缩放或点击适合页面。搜索框输入文字并回车。

编辑：在「开始」页把鼠标放到正文上会显示 I 形光标，单击定位，输入时自动切换到「编辑」。也可先点击「编辑」再选择正文。点击空白处、Enter、保存或翻页自动应用；Esc 取消本次输入。右侧只调整字号、颜色和样式。选择图片后在属性栏操作。文字过长、对象重叠、共享图片等不安全情况会拒绝操作。⌘Z 撤销，⇧⌘Z 重做。点击「另存副本」选择输出位置。

添加文字：点击「编辑 → 添加文字」，将跟随鼠标的文字框移到页面目标位置，点击后直接输入。点击空白处或 Enter 完成，Shift+Enter 换行，Esc 取消。无需填写坐标；超出页面无法容纳时保留草稿供修改。

转换：Word 输出文字段落、Excel 输出表格/文本行、PowerPoint 输出页面图片。导入 DOCX 会重新排版文字和表格。复杂排版不能保证保留。

“转换”标签中的 Word、Excel、PPT 快捷按钮按所选格式直接导出，只需选择保存位置。“开始 → 转换”提供格式选择。导出其他格式不会清除当前 PDF 的未保存状态；取消保存不会修改文档。

OCR：对未含文字、未旋转的扫描页点击文字识别，生成隐藏可搜索文字层。识别可能有误；当前不提供 OCR 人工纠错或扫描图中文字重绘。

设置：右上角齿轮→界面语言→简体中文/English；即时生效，不翻译或清空 PDF 内容。应用使用本地处理，不接入 WPS AI 服务。

批量转换：转换 / 批量处理 → 批量转换 → 选择 PDF 文件 → 选择保存文件夹 → 检查输出清单 → 开始批量转换。可取消；全部成功后在访达中打开结果。磁盘文件不包含未另存的编辑。扫描件转 Word、Excel、TXT 前先 OCR 并另存。

关键词批注（0.1.10）：打开 PDF →「批注」→ 高亮 / 下划线 / 删除线，输入关键词与页码范围，选择颜色和透明度，检查匹配数量后预览应用。也可从「批量处理 → 关键词批注」进入。原文字、字体和底图保留；「管理关键词批注」可选中并删除本功能添加的标记，支持撤销、重做和另存重开。扫描件请先 OCR。搜索不区分 ASCII 大小写，按子串匹配；同类型同区域自动跳过。删除线只是标记，不能用于遮盖或删除敏感信息。

最小步骤（0.1.11）：旋转、增删和移动页面直接生效；图片选择文件后直接插入/替换，删除和属性设置不再重复确认。页面管理选好范围后执行一次，拖动顺序后点“应用新页序”。关键词批注核对匹配清单后点“应用修改”；添加文字、水印、页眉页脚和画布尺寸也可直接应用，效果预览为可选。所有修改仍经后台校验，可撤销。全文替换和 OCR 暂保留排版/识别结果核对。
