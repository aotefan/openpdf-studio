# 中文界面视觉验收记录

用户指定实际 WPS 中文界面作为参照，故采用实际截图而非生成式概念图。基准：research/evidence/wps-zh-CN-edit.png。实现：tests/results/openpdf-zh-CN.png。两者已通过 view_image 实际查看。

没有 Browser/IAB 工具可用；使用 Playwright 的 Electron driver 直接测试桌面应用，而非模拟静态浏览器页面。开发测试窗口内容区设为 1496×855，WPS 总窗口 1496×855；WPS 截图含阴影/原生标题栏，Electron capturePage 仅网页内容。这一差异已记录，不能把当前截图称为严格逐像素一致。

|对比点|观察与处理|
|---|---|
|骨架|保留文件标签→功能标签→图标工具栏→左缩略图/中央页面/右属性→底栏|
|文字|界面中文为主；菜单、属性、弹窗、错误使用语言资源；PDF 示例仍含英语，按用户要求不翻译正文|
|字体与密度|系统 PingFang/系统 UI 字体；正文与 chrome 分开；13px UI、12px 工具标签|
|配色|浅灰 chrome、灰画布、白纸；独立品牌蓝色替代 WPS 红色，不复制商标|
|图标|Lucide 开源线框图标；无 WPS 图标资源|
|交互状态|选中文本蓝框；缩略图活动背景；无图片页禁用图片编辑；撤销/重做按状态启用|
|留白与面板|左184/右246点；相对 WPS 的宽导航面板缩窄，给属性栏和纸张空间|
|差异|未复刻所有 WPS 批注/保护/填写签名功能；不展示无实现的占位按钮；AI/会员/账号/云入口按需求排除|
|文案差异|“开始/编辑/页面/转换”等保留结构；独立品牌、功能限制说明和预览控件为必要独立产品文案|

当前属于核心布局对应的功能原型，不是对完整 WPS 的 10/10 像素复刻。整体视觉相似不能替代内容流/重新打开/差异测试。移动端不属于桌面产品目标；最小窗口980×640，后续增加窄窗口专项回归。

## 0.1.1 页面内文字输入
WPS 基准：`research/evidence/wps-inline-click-rea.png`、`wps-inline-typed-focused.png`。单击文本进入页面内对象编辑，并切换文字编辑功能区。OpenPDF 实现：`tests/results/inline-edit-zh-CN.png`；直接输入、悬浮预览/取消、侧栏仅属性。仍存在差异：WPS 可操作段落块，本实现以安全文本 span 为单位；本实现强制引擎预览后提交。浏览器编辑字形是近似字体，最终以 PDF 引擎预览为准。
